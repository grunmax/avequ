\section*{Core Idea}

In V.F.S., a \emph{death/reset event} is not the end of the system. It is a hybrid transition: the continuous life-flow is interrupted by a death-event, after which a discrete reset may return the system into the active domain.

\[
\text{life-flow}
\quad\longrightarrow\quad
\text{death event}
\quad\longrightarrow\quad
\mathfrak R
\quad\longrightarrow\quad
\text{new life-arc}.
\]

Thus death is not modeled as merely another infinitesimal step of the same differential equation. It is a change of mode: from continuous flow to a discrete Resurrectio jump, and then back to continuous flow.

\section{Before the Event: Life Inside the Active Domain}

As long as the trajectory remains inside the active domain \(\DA\), the usual Open-Gate dynamics operate:

\[
\dot\sigma=(\gamma-\delta u)\tanh(\kappa\sigma),
\]

\[
\dot\lambda=-\dot\sigma+\Igate,
\]

\[
\dot\Om=\alpha\lambda.
\]

Here \(\sigma\) is resistance, \(\lambda\) is Sophia, and \(\Om\) is the Brim of the Vessel. Resistance is either intensified or purified; Sophia grows through the transmutation of resistance and through the Open-Gate inflow; the Brim expands through Sophia.

In the updated Lyapunov proof, \(\DA\) is positively invariant. This means that the continuous flow itself does not fall through the boundary of the active domain. A death-event is therefore modeled as \emph{exogenous}: death strikes at an unpredictable time while the system is still mathematically inside the live domain.

\section{The Death Event: Interruption of the Life-Arc}

Immediately before the death-event, the state has the form

\[
x^-=(\sigma^-,\lambda^-,V,F,\Om^-)
\in \DA.
\]

This means that the system is still within the active domain, but the continuous life-arc is interrupted. In V.F.S. language, death-like closure is not merely internal exhaustion. It is an event that interrupts the flow and requires a different kind of operator.

The required operator is not another differential term. It is a reset map.

\section{The Reset Map \texorpdfstring{\(\mathfrak R\)}{R}: Reconfiguration of the Old Shell}

The reset is written as

\[
\mathfrak R:
\quad
x^-\longmapsto x^+.
\]

In the linear-metabolism version, it acts as follows:

\[
\sigma^+=q_R\sigma^-,
\qquad
0\le q_R<1.
\]

This means that part of the old resistance is removed. If \(q_R=0\), resistance is maximally cleansed. If \(q_R\) is close to \(1\), the cleansing is weak.

The key Sophia update is

\[
\lambda^+=\lambda^-+(1-q_R)\sigma^-.
\]

Thus resistance does not simply disappear. The reduced portion of \(\sigma\) is metabolized into Sophia:

\[
\text{resistance shell}
\quad\longrightarrow\quad
\text{transformed wisdom}.
\]

Will and Action remain continuous in the basic reset:

\[
(V,F)\ \text{continuous},
\qquad
u^+=\sqrt{VF+\varepsilon}=u^-.
\]

Equivalently, the personal continuity of the trajectory is not destroyed. The reset does not create a different being from nothing; it reconfigures the same trajectory after the death-event.

Finally, the Brim expands:

\[
\Om^+=\Om^-+\kappa_R\Grec^-.
\]

The accumulated received grace \(\Grec^-\) does not merely add energy. It expands the capacity of the Vessel.

\section{Why the Reset Is Not Arbitrary: The Grace Window}

The reset is not always admissible. The received grace at the moment before death must lie in a specific window:

\[
\max\{R_c,R_{\min}^{\rm ceil}\}
\le
\Grec^-
\le
R_{\max}.
\]

The lower theological threshold is

\[
R_c=C_\sigma-\sigma_0-\lambda_0.
\]

It says that enough received grace must be present so that Sophia cannot be extinguished by resistance.

The second lower bound is

\[
R_{\min}^{\rm ceil}
=
\frac{(1-q_R)\sigma^-}{q^*\kappa_R}.
\]

It says that if much resistance is converted into Sophia, the Brim must expand enough to absorb that converted wisdom without breaking the admissible \(q\)-ceiling.

The upper bound is

\[
R_{\max}
=
\frac{\Om^-(r^--r_*)}{\kappa_R r_*}.
\]

It prevents over-dilution. Too much unmeasured expansion would push the system below the lower radial corridor.

Therefore the V.F.S. reset logic is:

\[
\text{not enough received grace}
\quad\Longrightarrow\quad
\text{final closure};
\]

\[
\text{too much unmeasured expansion}
\quad\Longrightarrow\quad
\text{over-dilution};
\]

\[
\text{measured received grace}
\quad\Longrightarrow\quad
\text{Resurrectio}.
\]

Grace is necessary, but grace does not abolish measure, form, or the geometry of the Vessel.

\section{After the Reset: Return to the Active Domain}

If the admissibility conditions hold, then

\[
x^+=\mathfrak R(x^-)
\in \DA.
\]

The Lyapunov functional remains bounded:

\[
\Lvfs(x^+)\le L_R.
\]

After the reset, a new life-arc begins:

\[
x^+
\quad\longrightarrow\quad
\text{continuous flow again}.
\]

Thus the V.F.S. death/reset event has the form

\[
\boxed{
\text{continuous flow}
+
\text{discrete Resurrectio jump}
+
\text{continued flow}
}
\]

rather than an unbroken differential evolution.

\section{Why Resets Do Not Become Infinite Chaos}

The model also includes a non-Zeno dwell-time condition:

\[
\Delta t_j\ge \Delta t_*>0.
\]

This means that resets cannot accumulate infinitely many times in finite time. Each life-arc has duration. Each reset has measure. The hybrid trajectory can therefore remain forward-complete across an infinite sequence of life-arcs and admissible resets.

Theologically, this means that crises do not fragment the person into infinitely many instantaneous deaths. Rupture can happen, but it remains ordered.

\section{Theological Reading}

The death/reset event can be read as a Paschal sequence:

\begin{enumerate}[label=\arabic*.]
  \item \textbf{Tetelestai}: the old form is completed.
  \item \textbf{Death-like closure}: the continuous trajectory is interrupted.
  \item \textbf{Resurrectio reset \(\mathfrak R\)}: resistance is reduced, part of resistance becomes Sophia, and the Brim expands through received grace.
  \item \textbf{Anastasis}: the system returns into the live domain.
  \item \textbf{Epektasis}: the expanded Vessel can continue growing beyond its former shell.
\end{enumerate}

In one sentence:

\begin{quote}
\emph{A death/reset event in V.F.S. is a structurally admissible Resurrectio jump in which the old resistance-shell is reduced, part of it is metabolized into Sophia, received grace expands the Brim, and the system returns to the active domain for a new life-arc.}
\end{quote}
